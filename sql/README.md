# SQL Analytics Repository

This directory contains standalone, production-tested SQL queries corresponding to the 25 analytical questions from `Cricbuzz.docx`.

## Directory Structure:
- `beginner/`: Queries 1–8 (`q01.sql` to `q08.sql`) — Basic filtering, sorting, aggregations, and grouping.
- `intermediate/`: Queries 9–16 (`q09.sql` to `q16.sql`) — Multi-table joins, subqueries, `CASE WHEN`, conditional aggregations.
- `advanced/`: Queries 17–25 (`q17.sql` to `q25.sql`) — Window functions (`RANK()`, `ROW_NUMBER()`, `LAG()`), CTEs, standard deviation, time-series analysis, and complex weighted ranking algorithms.
